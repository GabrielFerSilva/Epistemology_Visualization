Como utilizar o site

Use os filtros no canto superior esquerdo para localizar autores ou ideias. Clique nos nós ou arestas do grafo para ver detalhes à direita. Utilize o botão com símbolo de relógio para mostrar ou ocultar a barra superior.

Use a linha do tempo para filtrar até que ano os autores e ideias são exibidos. Clique no botão "⟷ Intervalo" para definir um intervalo de anos. Clique no botão "▶ Iniciar" para animar a linha do tempo.

Utilize o botão de interseção, no canto inferior esquerdo para descobrir ideias compartilhadas entre autores.

Para explorar: selecione um autor ou ideia, clique no grafo, ou utilize o botão "▶ Iniciar" para animar a linha do tempo.

Sobre o site

Este site foi desenvolvido como projeto final da disciplina HU31 - Epistemologia da Ciência, no IMPA Tech. O objetivo é explorar a relação entre autores e ideias ao longo do tempo, visualizando conexões e interseções de forma interativa.

Desenvolvido por: Arthur Farias Zaneti, Bruno Pereira de Paula, Gabriel Ferreira Silva, Igor Augusto Zwirtes, Pedro Pereira Carvalho
